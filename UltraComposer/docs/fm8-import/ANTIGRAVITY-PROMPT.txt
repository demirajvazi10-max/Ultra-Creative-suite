You are working on "Ultra Composer", an accessible music composition app for Windows
(.NET 8 WPF front end in src/App, native C++ audio engine in src/AudioEngine, C# interop
in src/Interop). The author is blind and uses JAWS; every UI change must stay fully usable
with a screen reader and keyboard, and also clear for sighted mouse users.

GOAL
Let Ultra Composer import Native Instruments FM8 presets (.nfm8 files) into its built-in
"Ultra FM" synthesizer, as a close approximation of the original sound.

TASK 1 - Reverse-engineer the E8MF parameter block (the main job)
Use nfm8_decode.py (or your C# port) to extract the parameter block of all 61 presets and
work out its layout and meaning. Suggested method is in the notes ("Suggested approach").
Key facts: mostly little-endian float32 plus u32 counts; NOT fixed length (2987..4571
bytes) because of variable-length arrays (likely envelope breakpoints); 12 presets are
built from FM8's "init sound" starting patch and are the best baseline.
FM8 background: 8 operators (A-F sine-type operators, X noise operator, Z filter), a free
modulation matrix with feedback, multi-breakpoint envelopes, keyscaling, LFOs,
arpeggiator, effects, morph square with 4 snapshots.
Priorities, in order: (a) parse the block structurally so every file is consumed from
start to end without leftover bytes; (b) identify per-operator ratio, output level and
envelope; (c) identify the modulation matrix / feedback; (d) everything else is optional.
For every field you identify, record in NFM8-FORMAT-NOTES.md: offset or position in the
structure, type, observed range, your interpretation and a confidence level
(confirmed / likely / guess). Move items from "Open" to "Verified" only when confirmed.

TASK 2 - C# importer
- New file src/App/Nfm8Importer.cs: port of the decoder + your parameter parser +
  a mapper that produces Ultra FM settings (the SoundParam IDs and values).
- Mapping rules: choose the 6 most important FM8 operators (those that are audible or
  modulate audible ones), pick the Ultra FM algorithm whose topology is closest to the
  FM8 matrix, convert ratios (clamp to 0.5..16), levels (0..1), envelopes to ADSR
  (attack/decay/sustain/release, clamped to the ranges in SoundParams.h), and feedback.
  Ignore what Ultra FM cannot do. Keep the mapping in one clearly commented place so it
  can be tuned later.
- Apply the result through the existing AudioEngineInterop.SetSoundParam calls only.
  Do NOT change the native C++ engine or any P/Invoke signatures.
- Fail gracefully: an unreadable or unsupported file shows a clear spoken/visible message
  (localized), never crashes.
