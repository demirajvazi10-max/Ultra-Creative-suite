## Ultra Composer 2.2

**Download the installer below and run it.** Windows will ask for
administrator permission - that's normal and expected. Ultra Composer
needs the .NET 8 Desktop Runtime; the installer tells you if it's missing.

Ultra Composer is an accessible, keyboard-first music workstation: play
from the computer keyboard or a MIDI keyboard, sequencer, arranger,
multi-track mixer with WAV export, auto-accompaniment, the Ultra FM
synthesizer, SoundFont and VST3 instruments.

### New in 2.2

- **Sound library** at the top of the Instrument bank view: all your
  sounds in one place, sorted into categories (Standard, FM8, Oriental,
  My sounds, plus any category you create). Pick a category, then press
  Enter, Space or double-click on a sound to load it - no more hunting
  for files. "Add a sound to the library" copies your own banks and
  sounds in; categories are folders in Documents\Ultra Composer\Library.
- **FM8 sound import (.nfm8)**: Native Instruments FM8 presets are
  converted into Ultra FM - operator ratios, modulation routing and
  amounts, output levels, feedback and envelopes. It is a close
  approximation (Ultra FM has 6 operators and 8 algorithms; FM8's X and Z
  operators, LFOs and effects are not converted).
- **11 FM8 sounds by Senad** ship with the app in the FM8 category.
- Choosing a file with "Browse..." now **loads it right away** (banks,
  layers, tracks, auto-accompaniment, drums, VST3).

### New in 2.1

- New look: dark theme, coloured sections, a navigation bar and an
  **on-screen piano keyboard** that lights up as you play and can be
  played with the mouse.
- Notes play from the computer keyboard **anywhere in the window**, not
  only in the performance field (can be turned off in the View menu).
  With a screen reader running, letters in lists still jump to items.
- **Pitch bend** moved to the key left of 1 (down) and 1 (up), so it
  works with JAWS and leaves the arrow keys free.

### Performance keyboard shortcuts

Key left of 1 / 1 (hold) = pitch bend, Space (hold) = sustain pedal,
F2/F3 = modulation, F4/F5 = transpose, F6 = arpeggiator,
F7 = portamento, F8 = poly/mono/legato, F9 = effects, Home = stop all
notes, Up/Down = next sound.

### Accessibility

Built for the keyboard and screen readers (JAWS, NVDA) first and fully
usable with the mouse: every setting is reachable from the keyboard and
every change is spoken right away. Fully bilingual (English/Serbian),
with a built-in user guide (Help > User Guide).

### System requirements

- Windows 10/11 (64-bit)
- .NET 8 Desktop Runtime
- Optional: a MIDI keyboard, SoundFont (.sf2) banks, VST3 instruments,
  FM8 (.nfm8) sounds
